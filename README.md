# Manufacturing Community Database Management System

This group project focuses on designing and implementing a centralized database system for the Manufacturing Community at King Abdulaziz University. The club was established in January 2017 and aims to support innovation, manufacturing, and entrepreneurship by helping students transform their ideas into tangible products.

## Project Overview
The Manufacturing Community currently relies on Excel, Google Sheets, and Google Forms to collect and store data manually. This process creates several problems, including:
- Data entry errors due to missing validation rules
- Lack of direct data sharing between departments
- Difficulty updating information across departments
- Time-consuming and inefficient data transfer between different tools

## Objective
The main goal of this project is to develop a unified database system that allows the club to store, manage, and retrieve data efficiently and accurately. The system will help improve data quality, support department integration, and simplify updates and access to information.

## Proposed Solution
The proposed database system will:
- Centralize all club data in one place
- Enforce data validation rules and field constraints
- Allow departments to access and update shared data easily
- Improve communication and coordination between departments
- Support complaint and suggestion handling more effectively

## Importance of the Database
A centralized database is essential for the club because it:
- Improves operational efficiency
- Ensures secure and organized storage of information
- Reduces data loss and duplication
- Increases the accuracy and consistency of records
- Supports better decision-making
- Promotes integration across departments

## Data Collection
The required information for the database design was gathered using:
- Interviews with the club’s HR Manager
- A questionnaire to understand the club’s business rules and data requirements

 ## Skills Gained
This project helped develop important skills such as:
- Database design and modeling
- Data analysis and problem solving

## Conclusion
This project aims to provide the Manufacturing Community with a reliable and efficient database system that improves data management, supports collaboration, and enhances overall organizational performance.
